# Secretly

**Live demo:** https://mirjana3.github.io/Secretly/

Secretly is a web app for organising a Secret Santa gift exchange. Create a room, invite friends with a code, draw names, and get gift ideas based on your match's quiz answers and your budget.

## Features

- Sign up and log in with email or Google
- Gift quiz: interests, clothing size, favorite colors, dislikes and a wishlist
- Rooms with a name, budget and exchange date, joined with a code
- Live lobby where members appear in real time
- Fair draw where everyone buys for exactly one person
- Private match that only you can see
- Gift ideas within budget, which you can save
- Profile with saved gifts and recent activity

## Tech stack

HTML, CSS, JavaScript and Firebase (Authentication, Firestore, Hosting).
